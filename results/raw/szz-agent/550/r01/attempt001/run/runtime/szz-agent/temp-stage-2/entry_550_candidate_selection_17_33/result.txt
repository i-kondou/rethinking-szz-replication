The fix commit (fix_commit_diff.txt) corrects a single line in JavaSource/org/unitime/timetable/action/InstructorDetailAction.java: in the "no committed timetable" branch of the WebTable construction for the instructor's class-assignment table, the header array had 6 entries (Class, Check Conflicts, Share, Teaching Responsibility, Limit, Manager) but the alignment array had only 5 "left" entries. WebTable requires the header and alignment arrays to be the same length, so this mismatch caused an ArrayIndexOutOfBoundsException whenever an instructor was assigned to classes but no timetable had been committed yet. The fix simply appends a 6th "left" to the alignment array.
