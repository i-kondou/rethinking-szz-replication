EXPLANATION:
The fix commit changes this line in LocalInspectionsPass.java:

    tooltip = XmlStringUtil.wrapInHtml(message.startsWith("<html>") ? XmlStringUtil.stripHtml(message): XmlStringUtil.escapeString(message)) + link ;

to:

    tooltip = XmlStringUtil.wrapInHtml((message.startsWith("<html>") ? XmlStringUtil.stripHtml(message): XmlStringUtil.escapeString(message)) + link);

The bug is a misplaced closing parenthesis: `link` was being concatenated to the tooltip string *outside* the `wrapInHtml(...)` call instead of *inside* it. This means the link (e.g. a "More info" / navigation link appended to warning tooltips) ended up appended after the closing `</html>` tag produced by `wrapInHtml`, which caused the tooltip/warning to not render (or not display) correctly in the editor — consistent with the bug report "Not all warnings are displayed in the editor."
