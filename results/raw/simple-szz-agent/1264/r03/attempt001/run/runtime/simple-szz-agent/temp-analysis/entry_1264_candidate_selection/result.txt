The fix commit changes RuleSet.java's getParents() method from
`SConceptOperations.getAllSuperConcepts(nextConcept, false)` to
`SConceptOperations.getDirectSuperConcepts(nextConcept, false)`. Using
getAllSuperConcepts (which returns the full transitive closure of super
concepts) instead of getDirectSuperConcepts corrupts the concept-hierarchy
traversal used by the type-system rule dispatcher (SingleTermRules), which
walks getParents() step-by-step expecting only the immediate parents at each
level. This caused rule lookup/dispatch to misbehave for certain
overload-resolution scenarios, producing the reported typesystem error for
`String a="abc"; a+='d';`.
