The fix commit changes two lines in PatriciaTreeMutable.reclaim():

back to using `source.currentNode` instead of the cached local variable `sourceNode`:

`source.moveDown()` mutates `source.currentNode` to point at a new (child) node. After that
call, code that keeps using the old cached `sourceNode` variable instead of re-reading
`source.currentNode` operates on the wrong (stale/expired) node — this is exactly the
"weird reclaim bug" being fixed.

is the commit that added the `final NodeBase sourceNode = source.currentNode;` /

(no caching, no bug). candidate_12 contains a diff textually identical to the fix commit's
diff itself, meaning it is not another bug introduction but rather where this exact bug
was already being corrected/re-corrected — confirming candidate_11 as the true origin of
