The bug is a misplaced closing parenthesis: `link` (the "Show more/inspection details" HTML anchor appended to every warning tooltip) was being concatenated OUTSIDE the wrapInHtml(...) call instead of inside it. Since wrapInHtml() wraps its argument in `<html>...</html>`, appending `link` after the closing `</html>` tag produces malformed/truncated HTML for the tooltip. Swing's HTML renderer (and the tooltip display logic) then fails to render or fully display these tooltips, which is consistent with the reported symptom "Not all warnings are displayed in the editor" - warnings whose tooltip HTML got corrupted this way were not shown properly.
