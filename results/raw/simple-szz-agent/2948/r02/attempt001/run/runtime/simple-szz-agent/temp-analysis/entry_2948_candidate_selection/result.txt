The fix commit (fix_commit_diff.txt) modifies NativeND2Reader.java's metadata parsing loop, changing:

    while (sb.charAt(sb.length() - 1) != ':' && sb.indexOf("_") < 0 && i < lines.length) {

to:

    while ((sb.length() == 0 || sb.charAt(sb.length() - 1) != ':') && sb.indexOf("_") < 0 && i < lines.length) {

This addresses a StringIndexOutOfBoundsException that occurs when `sb` is empty (i.e., `sb.length() == 0`), because calling `sb.charAt(sb.length() - 1)` on an empty StringBuffer evaluates to `sb.charAt(-1)`, which is invalid.
