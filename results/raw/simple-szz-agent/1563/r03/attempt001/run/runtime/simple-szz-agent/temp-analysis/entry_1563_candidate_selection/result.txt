The fix commit changes java/src/libbun/parser/ast/ZNode.java, in the ZNode constructor:

-		ParentNode.SetChild(this, ZNode._EnforcedParent);

This restores a direct field assignment (`this.ParentNode = ParentNode;`) in place of a call to `ParentNode.SetChild(this, ZNode._EnforcedParent)`. The buggy version is unsafe because in the constructor, `ParentNode` can legitimately be null (e.g. when constructing a root/top-level node that has no parent yet). Calling `.SetChild(...)` on a null `ParentNode` throws a NullPointerException, whereas a direct assignment `this.ParentNode = ParentNode;` safely handles the null case.
